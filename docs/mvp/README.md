# MVPs

Each MVP lives in its own numbered folder, `NN-slug/`, with the same file set:
`README.md` (problem, goal, core flow, users), `scope.md`, `rules.md`,
`domain.md`, `meta-requirements.md` and `success-metrics.md`.
These docs are the source of truth for what each MVP builds and why. The stack
they build on is shared across MVPs and lives in
[`docs/architecture/tech-stack.md`](../architecture/tech-stack.md). When an
MVP ships, move it from Current to Done here and in [`AGENTS.md`](../../AGENTS.md).
