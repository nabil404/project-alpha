# Considered and not chosen

Alternatives evaluated during the stack decision and rejected, with the reason.
`AGENTS.md` links here; read it before proposing any of these again.

| Option                    | Why not                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CrewAI                    | Python-only, and multi-agent overhead we don't need.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Clerk                     | User data stored externally; all user data must stay in our own database.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Keycloak                  | A separate Java server to operate, with higher RAM than the VPS budget allows.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Passport                  | Session assumptions clash with our design, and strategy maintenance is limited.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Arctic                    | Deprecated by its author.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| pg-boss                   | BullMQ preferred.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Prisma                    | Rejected for SQL control, built-in row locking, and native Better Auth support — first for Kysely, now Drizzle.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| TypeORM                   | Re-examined Sep 2026, not on the old reason: pairing it with Better Auth's own adapter removes that objection, and TypeORM 1.0 is actively maintained again. It loses to Drizzle on two points — Better Auth would self-migrate on its own unversioned schedule, and business tables could not FK to `organization(id)` without a hand-written migration. Drizzle folds both into one pipeline.                                                                                                                                                                                                                                                                                 |
| Per-module schema files   | Extra build step and an ordering file; one sectioned schema barrel is enough.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Atlas                     | Replaced by drizzle-kit Sep 2026. Community edition cannot diff extensions, functions, sequences, views, triggers, RLS policies or grants — all Atlas Pro ($9/seat/month), against the no-recurring-cost principle. That is most of this schema: `pgcrypto`, `app_current_merchant()`, every tenant policy. So `schema.sql` could never be the complete desired state, `migrate diff` could not detect drift in any of it, and `db:diff` failed outright on `CREATE EXTENSION` without a login. It also needed a CLI install, Docker for its shadow database, and `atlas.sum` rehashing.                                                                                        |
| Kysely                    | Replaced by Drizzle Sep 2026, alongside Atlas. Nothing was wrong with it — but its types came from kysely-codegen against a live migrated database, needing Docker and a CI drift check, and Better Auth's SQL had to be pasted in by hand. Drizzle infers types from the schema and consumes Better Auth's generated schema directly.                                                                                                                                                                                                                                                                                                                                          |
| `merchant_id` = `user.id` | Evaluated Sep 2026 while scoping tenancy. Tempting: it drops the Organization plugin's three tables and the signup orchestration they need, and §5 defers team roles anyway. The data migration out of it would also have been cheap — one `organization` row per user with a matching id keeps every `merchant_id` valid. Rejected because a seller may hold several organizations later, at which point tenant stops being a function of the logged-in user and becomes a selection: every endpoint written against `tenant == session.userId` would have to be unpicked, which is a codebase-wide edit rather than a migration. `merchant_id` references `organization(id)`. |
| Next.js                   | An unneeded server layer once NestJS owns the backend.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Anthropic SDK alone       | Replaced by the AI SDK for provider independence.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| nestjs-zod                | Evaluated Sep 2026 for OpenAPI docs. Its peer range stops at `@nestjs/common` ^11, so it does not install cleanly on Nest 12, and it works through `createZodDto` classes — the parallel DTO layer `backend-engineer` rules out. Nest 12 and `@nestjs/swagger` 12 cover the same ground natively: `@Body({ schema })` takes a Zod schema as a Standard Schema, and swagger converts it into the document.                                                                                                                                                                                                                                                                       |
